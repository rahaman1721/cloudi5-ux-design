# Cloudi5 Technologies — UI/UX Design

## Project Overview

Internal workflow and interface design project for **Cloudi5 Technologies**, focusing on responsive web and mobile interface design for internal tools and business workflows.

## My Role

UI/UX Designer — responsible for designing user-centric, responsive interfaces from research through to high-fidelity prototypes.

## Contributions

- Responsive web interface design
- Mobile interface design
- User flow mapping and documentation
- Figma design system development
- Component library creation
- Interactive prototype development
- Usability-focused design decisions
- Design handoff and specification documentation

## Design Process

### Discovery
- Stakeholder requirements gathering
- User needs analysis
- Workflow documentation and mapping

### Design
- Low-fidelity wireframes
- User flow diagrams
- High-fidelity Figma screen designs
- Responsive breakpoint designs (desktop, tablet, mobile)

### Prototype
- Interactive Figma prototypes
- Usability walkthrough sessions
- Design iteration based on feedback

## Tools Used

- Figma (design and prototyping)
- Miro (user flow mapping)
- Adobe Illustrator

## Outcome

Design system and interactive prototypes delivered. Received positive feedback from the internal design and development team.
